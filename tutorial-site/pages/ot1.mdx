# O1 · 两个人的修改为什么互相覆盖

A、B 同时修改一份“项目周报”：

```text
A 在开头添加“八月”
B 在结尾添加“已完成”
```

正确结果应该同时保留两个人的内容。如果每次输入都发送完整字符串，服务端只能用后到的全文覆盖先到的全文。

## 问题：全文只有结果，没有意图

```js
// A 发送
{ text: '八月项目周报' }

// B 发送
{ text: '项目周报已完成' }
```

服务端不知道 A 做的是“在开头插入八月”，也不知道 B 做的是“在结尾插入已完成”。它只能选择其中一份。

## 逐步观察覆盖过程

切换“A 的全文先到”和“B 的全文先到”。到达顺序不同，只会改变谁的内容被丢掉。

## 本章答案

全量广播的问题不是 WebSocket，也不是网络慢，而是消息缺少可合并的修改意图。两个完整快照只能互相覆盖。
