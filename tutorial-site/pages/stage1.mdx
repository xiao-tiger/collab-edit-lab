# Stage 1 · 已经传操作，为什么还是删错字

不再发送“整篇文档变成什么”，而是发送用户做了什么：

```js
{ kind: 'insert', pos: 0, str: '八月' }
{ kind: 'delete', pos: 3, len: 1 }
```

操作比全文更有信息，但 `pos` 属于操作生成时看到的旧文档。并发插入会让后续字符整体移动，旧坐标可能指向另一个字。

## 本章答案

操作携带了修改意图，但数字坐标不是永久身份。只要操作生成后有人在它左侧插入或删除，`pos` 就可能过期。
