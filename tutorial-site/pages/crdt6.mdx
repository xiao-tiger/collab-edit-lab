# C6 · 两个人同时插入第二段怎么办

文档最初只有两个段落：

```text
1. 开场
2. 结论
```

A、B 离线时都在下标 `1` 插入新段落。同步后，原来的下标已经无法表达谁应该排在前面。

## 不使用易变化的数组下标

Sequence CRDT 给每个段落或字符一个永久唯一 ID，并把插入描述成：

```text
创建节点 A1
把它放在节点 S1 后面
```

如果 A1、B1 都声明自己在 S1 后，它们就是并发兄弟节点。所有副本使用相同的 ID 排序规则，就能得到相同顺序。

## 为什么需要墓碑

B 可能在一个自己仍然看得见的段落后插入内容，而 A 已经删除了那个段落。如果 A 物理移除节点，之后收到 B 的插入时就找不到锚点。

因此删除通常先变成：

```js
{ id: 'S2', value: '正文', deleted: true }
```

读取文档时跳过它，遍历内部结构时仍保留它。安全清理墓碑需要确认相关副本都已看过删除，这是后续的 GC 工程问题。
