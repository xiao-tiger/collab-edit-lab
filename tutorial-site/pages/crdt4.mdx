# C4 · 被删除的标签为什么又复活了

文档原来有标签“需求”。A 删除它，B 还没有收到删除，双方随后同步：

```text
A 的标签：[]
B 的标签：[需求]
```

如果集合合并只是取并集：

```text
[] ∪ [需求] = [需求]
```

刚刚删除的标签复活了。问题是“空数组”没有记录这个标签曾经被删除过。

## 给每次新增一张身份证

每次新增都生成一个唯一事件 ID，也叫 `dot`：

```text
第一次添加需求 → 需求@S1
删除需求       → 删除 S1
重新添加需求   → 需求@B1
```

删除针对的是自己已经见过的新增事件，而不是模糊地写一句“需求不存在”。

## Add-Wins 和 Remove-Wins

它们都能收敛，区别是产品选择：

```text
Add-Wins：并发的新 dot 没被删除，所以元素存在
Remove-Wins：并发删除优先，所以元素不存在
```

CRDT 保证大家算出同一个答案，但不会替产品决定哪种答案更合理。普通文档标签常用 Add-Wins；权限关闭、安全状态更适合 Remove-Wins 或服务端权威。
