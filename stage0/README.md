# Stage 0：最笨的协同 —— 全量文本广播

## 运行

```bash
node stage0/server.js   # 端口 8000，开两个浏览器标签页访问
```

## 本阶段实现

- WebSocket 双向通道，服务端内存保存整篇文档（一个大字符串）
- 客户端每次输入，把**整篇文档**发给服务端
- 服务端全量覆盖、广播给其他人；新加入者拿到当前全文
- 策略：**last-write-wins（后到者胜）**

## 已知弊端

1. **并发互相覆盖**：两人同时打字，整篇文档互相顶掉，字符丢失，两边内容发散且无法察觉
2. **光标被拍飞**：收到远端更新直接覆盖 `textarea.value`，选区被重置
3. 没有"操作意图"的概念：服务端不知道用户到底改了哪里，无从合并

## 后续阶段如何解决

- **Stage 1**：引入操作模型（insert/delete），解决"互相覆盖丢字"，并做朴素光标修正
- **Stage 2**：引入版本号，让发散变得**可检测**
